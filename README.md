# CycleEffect

A new Flutter project.

## Getting Started

To run this project locally, you will need to have [Flutter](https://flutter.dev/docs/get-started/install) installed on your machine.

### Prerequisites

- Flutter SDK
- Android Emulator or iOS Simulator (or a physical device)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/ekrlstd/cycleeffect.git
    cd cycleeffect
    ```

2.  **Install dependencies:**
    ```bash
    flutter pub get
    ```

3.  **Run the application:**
    ```bash
    # To run on a connected device or emulator
    flutter run
    ```

### Troubleshooting

- If you encounter issues with `adb`, ensure your Android SDK `platform-tools` are in your PATH.
- Run `flutter doctor` to diagnose environment issues.
